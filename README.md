Плагин для AutoCAD и AutoCAD Plant 3D, который выгружает 3D-модели и технологические трубопроводы
в чистый **IFC** (IFC4 / IFC2x3) с честной B-Rep геометрией, правильной классификацией и семантическими
наборами свойств (Pset) — без падений процесса, без потери параметров и без коммерческих комбайнов.

[baidurovlabs.ru](https://baidurovlabs.ru) · лицензия [GNU GPLv3](LICENSE)

## Зачем
В базовом AutoCAD нет нативного прямого экспорта в IFC. В AutoCAD Plant 3D штатные инструменты
выгрузки либо отсутствуют, либо сводятся к тяжеловесным промежуточным форматам (NWCOUT / FBX / DXF / SAT),
которые теряют семантическую структуру: диаметры труб, спецификации, номера линий, материалы
и типы арматуры превращаются в немые геометрические болванки.

Существующие коммерческие плагины (AstraPlant, Codemill, MDC) либо привязаны к дорогим закрытым
лицензиям, либо падают с ошибками переполнения памяти на реальных промышленных узлах со сложными
блоками и тысячами отводов.

**При этом вся необходимая семантика в чертеже уже есть:**
- В Plant 3D: база данных проекта (`DataLinksManager`) хранит номер технологической линии, спецификацию,
  условный проход (DN), марку стали, расчётное давление и рабочую среду.
- В AutoCAD: топологическое B-Rep ядро (`acdbmgdbrep.dll`) содержит строгую граничную геометрию тел,
  а структура блоков и слоёв задаёт иерархию узлов.

DWG2IFC считывает топологию и свойства напрямую из памяти сессии AutoCAD и транслирует их в валидный IFC.

## Быстрый старт
Готовая сборка — в [Releases](https://github.com/AnT1pal/DWG2IFC/releases): скачайте
`DWG2IFC-Setup.exe`, запустите и нажмите «Установить плагин». Права администратора не требуются —
бандл регистрируется в пользовательском каталоге автозагрузки `ApplicationPlugins`.

```powershell
DWG2IFC-Setup.exe --install      # тихая установка
DWG2IFC-Setup.exe --uninstall    # удаление плагина и ярлыков
DWG2IFC-Setup.exe --status       # проверка статуса регистрации
```

Из исходников:

```powershell
git clone https://github.com/AnT1pal/DWG2IFC.git
cd DWG2IFC
powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт компилирует плагин под .NET 8.0 и регистрирует бандл в AutoCAD. Перезапустите AutoCAD:
на ленте появится вкладка **DWG2IFC** → **Экспорт в IFC**.

Команды в консоли AutoCAD / Plant 3D:
- `DWG2IFC` или `IFCEXPORT` — открыть диалог экспорта с выбором схемы, фильтров и координат;
- `PLANTTOIFC` — выгрузка с параметрами по умолчанию;
- `IFCRIBBON` — принудительно восстановить/активировать вкладку на ленте.

## Соответствие сущностей

DWG2IFC разбирает как технологические компоненты Plant 3D, так и общестроительные 3D-тела базового AutoCAD:

| Объект DWG / Plant 3D | Метод извлечения геометрии | Сущность IFC (IFC4 / IFC2x3) | PredefinedType / Классификация |
|---|---|---|---|
| Труба (`PIPE`, `AcPpDb3dPipe`) | B-Rep фасетирование тела трубы | `IfcPipeSegment` | `.RIGIDSEGMENT.` |
| Отвод, тройник, переход, фланец | B-Rep фасетирование фитинга | `IfcPipeFitting` | `.BEND.`, `.JUNCTION.`, `.TRANSITION.`, `.CONNECTOR.` |
| Кран, задвижка, клапан, заслонка | Граничная триангуляция арматуры | `IfcValve` | `.ISOLATING.`, `.REGULATING.` |
| Насос, компрессор | B-Rep сетка агрегата | `IfcPump` / `IfcFlowMovingDevice` | `.CIRCULATOR.` / `$` |
| Ёмкость, аппарат, резервуар | Твердотельная геометрия оборудования | `IfcEnergyConversionDevice` | Оборудование / Резервуар |
| Опора трубопровода, подвеска | Тесселяция элементов опоры | `IfcDiscreteAccessory` / `IfcFastener` | Элементы крепления |
| Металлопрокат Plant 3D (`Structure`) | B-Rep контур и выдавливание | `IfcBeam` / `IfcColumn` / `IfcMember` | Балки, колонны, связи |
| Твердотельное тело (`AcDb3dSolid`) | Аналитическая топология B-Rep | `IfcTriangulatedFaceSet` / `IfcFacetedBrep` | `IfcBuildingElementProxy` |
| Поверхность / Тело (`Surface`, `Body`) | Граничная оболочка AcBr | `IfcTriangulatedFaceSet` | `IfcBuildingElementProxy` |
| Область / Регион (`AcDbRegion`) | Триангуляция замкнутого контура | `IfcTriangulatedFaceSet` | Геометрическая грань |
| 3D-грань (`AcDbFace`) | Прямая 3/4-точечная полигональная триангуляция | `IfcTriangulatedFaceSet` | Полигональный фасет |
| Блок (`AcDbBlockReference`) | Рекурсивный обход элементов с учётом матрицы `BlockTransform` | Развёрнутая сборка компонентов | По дочерним телам блока |
| Сетка (`AcDbSubDMesh`, `PolyFaceMesh`) | Индексированные массивы вершин | `IfcTriangulatedFaceSet` | Фасетированная сетка |

2D-примитивы (отрезки, дуги, сплайны, размеры, текстовые аннотации) в 3D-тело не превращаются
и отсеиваются на этапе валидации геометрии.

## Свойства и наборы данных (Pset)
Каждый объект снабжается наборами параметров buildingSMART, которые формируются из атрибутов
Plant 3D DataLinks и системных метаданных AutoCAD:

1. **`Pset_Plant3D_Piping` (Технологические свойства):**
   - `LineNumberTag` — номер технологической линии;
   - `Size` / `NominalDiameter` — условный проход (Ду / DN);
   - `Spec` — трубная спецификация / мини-каталог;
   - `Description` / `ShortDescription` — наименование и заводская марка;
   - `Material` — марка стали / сплава;
   - `Service` — технологическая среда;
   - `DesignPressure` / `DesignTemperature` — расчётные параметры;
   - `Tag` — позиционное обозначение КИПиА и арматуры;
   - `Status` — статус проектирования (New, Existing, Demolition).

2. **`Pset_AutoCAD_Metadata` (Базовые свойства):**
   - `Layer` — исходный слой чертежа;
   - `Handle` — неизменяемый шестнадцатеричный дескриптор объекта в базе DWG;
   - `Color` — RGB / индекс цвета;
   - `Entity` — исходный тип класса AutoCAD (`AcDb3dSolid`, `AcPpDb3dPipe` и т.д.).

3. **Служебные идентификаторы:**
   - Каждому элементу присваивается детерминированный **IFC GUID** (22-символьный base64 по спецификации RFC 4122),
     вычисляемый на основе хэша дескриптора и параметров. При повторном экспорте геометрии GUID не изменяются,
     что предотвращает потерю связей и ложные коллизии в Solibri, Navisworks и BIMCollab.

## Производительность и стабильность
Плагин спроектирован для бесперебойной работы с крупными заводскими моделями и сложными сборками:

- **Потоковая запись (Stream I/O):**
  Генератор IFC пишет файл на диск через буферизованный `StreamWriter` по мере обхода чертежа.
  Файл не собирается целиком в оперативной памяти в виде гигантского DOM-дерева, поэтому экспорт
  модели на 500 000 полигонов укладывается в 150–200 МБ рабочей памяти процесса AutoCAD.
- **Сварка вершин (Vertex Welding):**
  Автоматическое объединение дублирующихся пространственных координат сетки с настраиваемым
  допуском (по умолчанию 0.5 мм) сокращает объём списка вершин и размер итогового IFC-файла на **50–70%**.
- **IFC4 TriangulatedFaceSet:**
  В схеме IFC4 используется компактное представление `IfcCartesianPointList3D` с единым массивом индексов
  треугольников. Это уменьшает размер файла в 3–4 раза по сравнению с устаревшим форматом `IfcPolyLoop` из IFC2x3.
- **Смещение удалённых координат:**
  Если чертёж выполнен в геодезических координатах (МСК / СК-42) с выносом на десятки километров от нуля,
  плагин позволяет сместить координаты геометрии в локальный ноль с фиксацией дельты смещения в метаданных площадки.

### Победа над падением кучи (0xc0000374) в B-Rep API
При разработке была выявлена и устранена критическая уязвимость автокадовского API:
в библиотеке `acdbmgdbrep.dll` классы итераторов `Element2d` и `Node` наследуются от `DisposableWrapper`
и хранят неуправляемые указатели на внутренний буфер фасеток нативного объекта `Mesh2d`.

При обработке модели из нескольких тысяч тел сборщик мусора .NET не успевал вовремя уничтожать
обёртки, и они попадали в очередь финализации. Когда нативный буфер уничтожался, отложенный вызов
финализатора приводил к обращению по освобождённой памяти и падению процесса AutoCAD с фатальной
ошибкой `STATUS_HEAP_CORRUPTION` (`0xc0000374` в `ntdll.dll`).

В DWG2IFC обход топологии изолирован в детерминированные блоки `using`: неуправляемые ресурсы
освобождаются немедленно, а вызовы финализаторов GC подавляются.

> **Результат натурного стресс-теста на реальном чертеже «Горка без крыши финал.dwg»:**
> Модель содержит **3 862 объекта** со сложнейшими блоками по **114 000+ граней**.
> Плагин обработал все **3 832 пространственных тела (свыше 300 000 полигонов)** без единого сбоя памяти
> с кодом возврата `0`.

## Честные ограничения
Мы не обещаем «волшебную кнопку, которая сделает всё сама». Границы работы определены строго:

- **2D-аннотации и каркасы:** Отрезки (`AcDbLine`), круги, полилинии и текст не образуют замкнутых
  тел и не экспортируются как IFC-геометрия. Для них предназначены чертежи 2D.
- **Глубина вложенности блоков:** Рекурсивный разбор блоков ограничен глубиной 8 уровней для защиты
  от циклических перекрёстных ссылок внутри повреждённых чертежей.
- **Некорректная геометрия (Non-manifold solids):** Если 3D-тело повреждено внутри DWG и ACIS/B-Rep
  ядро AutoCAD возвращает ошибку топологии при построении фасеток, плагин создаёт безопасный
  габаритный параллелепипед (Bounding Box B-Rep fallback) с сохранением всех свойств элемента,
  не прерывая экспорт остального чертежа.

## Кроссверсионность
Плагин собран под платформу **.NET 8.0 (x64)** и работает в современных версиях Autodesk:

| САПР | Среда исполнения | Совместимость |
|---|---|---|
| AutoCAD 2025 | .NET 8.0, x64 | Полная |
| AutoCAD 2026 | .NET 8.0, x64 | Полная |
| AutoCAD Plant 3D 2025 | .NET 8.0, x64 | Полная (с извлечением DataLinks) |
| AutoCAD Plant 3D 2026 | .NET 8.0, x64 | Полная (с извлечением DataLinks) |

Манифест бандла настроен на диапазон серий от `R25.0` до `R26.0`, что гарантирует автоматическую
загрузку во всех минорных обновлениях и сервиспаках AutoCAD 2025 и 2026.

## Архитектура
```
DWG2IFC/
├─ bundle/DWG2IFC.bundle/   ← автозагружаемый бандл Autodesk
│  ├─ PackageContents.xml   манифест регистрации, требования к среде, команды
│  └─ Contents/             иконки и скомпилированные бинарники net8.0
├─ src/
│  ├─ DWG2IFC/              ← основной плагин (AutoCAD .NET Extension)
│  │  ├─ Commands/          точки входа команд (DWG2IFC, IFCEXPORT, PLANTTOIFC, IFCRIBBON)
│  │  ├─ Geometry/          B-Rep фасетирование тел, сварка вершин (Vertex Welding)
│  │  ├─ Ifc/               потоковый писатель IFC (ISO-10303-21), генератор GUID
│  │  ├─ Plant/             динамическое извлечение свойств PnP DataLinks через рефлексию
│  │  ├─ Settings/          конфигурация экспорта (JSON в AppData)
│  │  └─ UI/                интерфейс WPF в стиле AutoCAD 2026, менеджер ленты (Ribbon)
│  └─ DWG2IFC.Setup/        ← автономный WPF/CLI установщик с внедрённым payload
├─ libs/AutoCAD_2025/       ← эталонные сборки AutoCAD API (.NET 8.0)
├─ build.cmd / build.ps1    скрипты сборки плагина и установщика
├─ install.ps1              развёртывание бандла в установленный AutoCAD
└─ pack.ps1                 сборка релизного дистрибутива в dist\
```

## Сборка и упаковка

Сборка из командной строки:
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Создание полного дистрибутива релиза:
```powershell
powershell -ExecutionPolicy Bypass -File pack.ps1 -Version 1.0.0
```

Скрипт формирует каталог `dist\`:
- `DWG2IFC-Setup.exe` — независимый инсталлятор со встроенным zip-архивом бандла;
- `DWG2IFC-1.0.0.zip` — бандл россыпью для ручной установки;
- `SHA256SUMS.txt` — контрольные суммы файлов.

## Связка с экосистемой
DWG2IFC является частью открытого конвейера бесшовной трансляции моделей:
```
AutoCAD / Plant 3D (DWG) ──[ DWG2IFC ]──► IFC4 / IFC2x3 ──[ IFC2RVT ]──► Revit (нативные элементы)
```
Родственный проект: [IFC2RVT](https://github.com/AnT1pal/IFC2RVT) — прямой импорт IFC в Revit
с построением нативных редактируемых стен, перекрытий, колонн и балок вместо мёртвых DirectShape.
